# Бункер Симулятор Релиз

Сборки **KOBLiK · Симулятор бункера** — десктоп-приложения для разработчиков
интеграций с KOBLiK Контроль. В одном окне работают плата весового бункера
(профиль weight3) и планшет оператора, а данные уходят в облако выбранного
окружения так же, как от настоящего бункера.

## Скачать

Последняя версия — на странице [Releases](../../releases/latest):

| Система | Файл |
| --- | --- |
| macOS, Apple Silicon (M1–M4) | `KOBLiK-Bunker-Simulator-<версия>-arm64.dmg` |
| macOS, Intel | `KOBLiK-Bunker-Simulator-<версия>-x64.dmg` |
| Windows, установщик (обновляется сам) | `KOBLiK-Bunker-Simulator-Setup-<версия>.exe` |
| Windows, без установки | `KOBLiK-Bunker-Simulator-<версия>-portable.exe` |

**macOS, первый запуск.** Сборка подписана без сертификата Apple, поэтому
система сначала откажется открыть приложение: «Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть».

## Обновления

Симулятор сам проверяет этот репозиторий: при запуске, раз в 6 часов и по
пункту меню «Проверить обновления…». Если вышла новая версия, он предложит
обновиться. Windows-установщик ставит её сам. На macOS и в portable-версии
откроется скачивание нового файла.

## Что нужно для работы

- учётная запись оператора или администратора модуля взвешивания в KOBLiK
  Контроль;
- бункер, на котором в реестре смонтирован контроллер;
- в организации включено «Автоматическое определение» техники (Настройки →
  Взвешивание) — без него облако не выдаёт бункеру справочник с пропусками.

Вопросы — в KOBLiK.
